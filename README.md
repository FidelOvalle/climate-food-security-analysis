# Climate Change, Tree Loss & Food Security Analysis

A collaborative data analysis project exploring relationships between climate change, tree loss, agricultural emissions, food production, and food insecurity across countries.

## Overview

This project combines multiple environmental and agricultural datasets to examine how changes in climate and land use relate to food production and food security. The analysis explores trends in agricultural CO2 emissions, temperature change, tree cover loss, food production, undernourishment, and population across countries and continents.

## Key Questions

- How are agricultural CO2 emissions related to temperature change?
- What patterns appear between tree cover loss and temperature change?
- How have food consumption emissions changed across continents?
- How do temperature changes relate to food production and undernourishment?
- How might tree cover loss relate to food production?
